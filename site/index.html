01做了什麼

學生找校園資訊時，常常不知道正式名稱怎麼講：想問「書可以延長嗎」，FAQ 上寫的卻是「續借」；想問「課不想上了」，正式說法是「停修」。單純比對關鍵字容易找不到。

這支 Python 程式使用 Embedding（文字向量）：呼叫 Gemini 把每一題 FAQ 和使用者的問題都轉成一串數字（向量），意思越接近的句子，向量方向也越接近。再用 餘弦相似度 排序，列出最相關的前 3 題。為了證明效果，另外做了一個不使用 AI 的「關鍵字比對」當對照組。

① 題庫data/faq.json
20 題常見問答
② 轉成向量Gemini embedding
題庫與問題各轉一次
③ 比對餘弦相似度
取分數最高的 3 題
④ 評估與發布算正確率 → results.json
Actions 部署到 Pages

02怎麼執行

# 1. 安裝套件（使用 uv）
uv sync

# 2. 設定金鑰：複製範例檔後填入自己的 Gemini API key
cp .env.example .env

# 3. 跑完整評估，結果會寫入 site/results.json
uv run main.py

# （可選）現場問一題
uv run main.py --ask "宿舍可以煮泡麵嗎"

# 4. commit 並 push，GitHub Actions 會自動部署本頁
git add -A && git commit -m "更新查詢結果" && git push

金鑰只存在 .env，已列入 .gitignore，不會上傳到 GitHub。GitHub Actions 只負責部署網頁，不呼叫 AI，所以不需要金鑰。
